# frontend/src/components/track/

## Purpose
Track-related UI components.

## Files
- `SimilarTracks.tsx` — Displays similar tracks for a given track; shows cover art, title, artist, BPM, Camelot key, and similarity score percentage
- `__tests__/SimilarTracks.test.tsx` — Unit tests (loading, data, empty states)

## Dependencies
- `useSimilarTracks` hook from `../../hooks/useSimilarTracks`
- TanStack Router `Link` for track navigation
