# Routes - CLAUDE.md

## Overview

TanStack Router file-based routes for the frontend application. Each `.tsx` file in this directory corresponds to a URL path. The route tree is auto-generated by the `@tanstack/router-vite-plugin` into `routeTree.gen.ts`. Route protection is handled in `__root.tsx` which redirects unauthenticated users away from protected routes.

## Key Functions/Exports

### __root.tsx (Route Protection)

```typescript
const PUBLIC_ROUTES = ['/', '/login', '/permission-denied', '/hello-search'];
function isPublicRoute(pathname: string): boolean
```

The root component checks authentication state and effective role:
- If `isLoading`, renders a spinner
- If effectively guest (not authenticated, guest role, or simulating guest) and on a protected route, redirects to `/permission-denied`
- Otherwise renders `<Outlet />`

### hello-search.tsx

```typescript
export const Route = createFileRoute('/hello-search')({ component: HelloSearchPage });
export default function HelloSearchPage(): JSX.Element
```

Manages local `searchQuery` state. Uses `useHelloSearch(query)` for search results and `useFeaturedTracks()` for default display. Shows `TrackCardSkeleton` during loading, error alert on failure, and `TrackCard` for each result.

### index.tsx (Home)

```typescript
export default function HomePage(): JSX.Element
```

Fetches recent tracks and library stats with role-aware scope (`'own'`, `'public'`, `'all'`). Displays stats cards, quick action buttons, and recent tracks list. Redirects to `/login` if not authenticated.

### login.tsx

```typescript
export default function LoginPage(): JSX.Element
```

Form with email/password validation, error display with Cognito error code mapping, auto-focus, and redirect after successful sign-in.

### signup.tsx

```typescript
export default function SignupPage(): JSX.Element
```

Two-step flow: signup form then 6-digit verification code entry. Handles `signUp`, `confirmSignUp`, `resendSignUpCode`.

## Usage Examples

### Adding a New Route

1. Create a new `.tsx` file in the appropriate directory (e.g., `routes/my-page.tsx`)
2. Export a `Route` using `createFileRoute`:
```typescript
import { createFileRoute } from '@tanstack/react-router';

export const Route = createFileRoute('/my-page')({
  component: MyPage,
});

function MyPage() {
  return <div>My Page</div>;
}
```
3. If the route should be public (accessible without auth), add it to `PUBLIC_ROUTES` in `__root.tsx`
4. The route tree is auto-generated on save by the Vite plugin

### Dynamic Route Parameters

Use `$paramName` in the filename:
```typescript
// routes/tracks/$trackId.tsx
export const Route = createFileRoute('/tracks/$trackId')({
  component: TrackDetailPage,
});

function TrackDetailPage() {
  const { trackId } = Route.useParams();
  // ...
}
```
